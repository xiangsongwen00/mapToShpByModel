# 道路与单体建筑提取——需求与设计摘要

## 1. 项目目标

基于约 0.52 米分辨率可见光卫星影像，建设本地运行的深度学习流程，实现：

1. 按影像范围下载 OSM 道路与建筑，生成初始标注；
2. 清洗、人工修正、切片和质检，形成可复用数据集；
3. 使用本地 NVIDIA 显卡分别训练道路、建筑分割模型；
4. 使用模型对新 TIFF 推理，输出栅格掩膜与矢量成果；
5. 三阶段相互独立，分别由目录内的 `index.py` 启动并提供可视化窗口。

详细方案见 `关于深度学习模型标注与训练以及生产设计书.md`。

## 2. 数据与任务

- 输入：`data/tiff/` 中的 RGB GeoTIFF。
- 当前数据：EPSG:4326，地面分辨率约 0.52–0.60 米。
- 道路：输出道路面掩膜，可进一步生成中心线。
- 建筑：输出地面底座掩膜，并矢量化为尽可能独立的单体建筑；卫星影像中的屋顶只作参考，高层建筑需校正偏角造成的屋顶位移。
- 样本域：城市道路、农村道路、城市建筑、农村建筑。
- 默认训练两个任务模型，训练/验证按城市、农村分层；配置允许改为四个场景独立模型。

## 3. 三阶段职责

### `makeLabel`

- 读取 TIFF 空间范围，下载/导入 OSM 数据；
- 坐标统一、几何修复、去重、裁剪、属性映射和栅格化；
- 人工增删、修边、复核，并标记城市/农村场景；
- 先按原图/地理区域划分训练、验证、测试集，再进行切片；
- 默认样本 `512×512`、步长 `256`，边缘补齐而不拉伸；
- 生成影像块、无损标签、预览图、清单和质检报告。

### `trainModel`

- 建议在 Conda `model` 环境运行；
- 使用本地 CUDA 显卡，支持混合精度、断点续训、早停；
- 道路、建筑分别训练，不混为一个训练任务；
- 记录配置、数据版本、随机种子、曲线、指标和最佳权重；
- 通用指标为 IoU/F1/Boundary F1；道路增加连通性评价，建筑增加实例分离评价；
- 导出权重时必须同时导出完整推理配置和模型卡。

### `getBuildAndRoad`

- 从 `getBuildAndRoad/config/` 读取模型包；
- 对大图滑窗推理，重叠区加权融合以避免拼接缝；
- 分别输出概率图、二值掩膜和矢量结果；
- 保持原影像坐标系、范围、变换矩阵和分辨率；
- 支持阈值、形态学后处理、建筑实例分离、道路中心线提取；
- 默认输出 GeoTIFF 和 GeoPackage；矢量数据只允许 GeoPackage 或 Shapefile，不使用 JSON/GeoJSON 承载矢量成果。

## 4. 可视化要求

三个 `index.py` 默认启动独立桌面窗口，同时保留 `--no-gui --config ...` 批处理模式：

- 标注窗口：影像/OSM/标签叠加、透明度、几何编辑、撤销重做、质检状态；
- 训练窗口：参数、GPU 状态、日志、曲线、预测预览、安全停止/继续；
- 推理窗口：批量影像、模型选择、进度、阈值预览、结果叠加和导出。

GUI 只负责交互，业务逻辑由 GUI 与 CLI 共用。三个阶段不得相互导入业务模块；公共地理、配置和日志能力放入 `common/`。

## 5. 关键约束

- OSM 仅作预标注，必须以影像可见内容为准人工复核；
- 同一原图、相邻重叠区不得跨训练/验证/测试集合，防止空间泄漏；
- 米制缓冲、面积和距离计算前必须投影，不能把 EPSG:4326 的度当作米；
- 标签使用无损格式，类别值固定为背景 0、目标 1、忽略 255；
- 不完整标注的未覆盖区域必须使用 255，不能默认当作背景 0；允许用少量负样本面图层标记典型难负样本并进行正负像元加权训练；
- 全部建筑、道路及派生矢量统一使用 GeoPackage，兼容性交付可使用 Shapefile；JSON/YAML/CSV 仅限非空间元数据；
- 每个权重必须可追溯到数据集、配置、代码和评价结果；
- 影像与 OSM 的下载、训练及成果发布须满足授权和署名要求。

## 6. 完成标准

- 三个阶段能分别从各自 `index.py` 启动和运行；
- 任一阶段失败不破坏原始输入和上一阶段已发布成果；
- 数据集可从清单复现，并通过尺寸、类别、空间参考、空标签和泄漏检查；
- 训练可中断恢复，能导出最佳权重、推理配置和评价报告；
- 推理结果与输入严格对齐，无明显切片接缝；
- 任一成果可定位到原图、模型、阈值、配置和运行日志。
